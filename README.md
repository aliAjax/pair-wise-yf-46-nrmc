# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 稿件版本与播出核对（/scripts）

- 每条口播、新闻片各绑定一份稿件版本；主编改标题或正文即生成新版本，已下发的旧版本自动作废，未播条目须导播重新确认后才能下发。
- 提词器断网时主播继续念缓存稿件，下发请求留在待发队列；链路恢复后自动重试未送达部分，并按条目编号 + 稿件版本对账：未播且版本不一致的条目挂起并列出差异，已播条目把实际念到的版本写入播出日志。
- 同一条目同一版本重复下发只记一次；重试只发没发出去的部分，已送达记录不动，已作废版本标记取代。
- 权限：确认、下发、对账仅导播可执行，改稿仅主编可执行，字幕与演播室只读；越权操作直接拒绝并记入稿件审计。

React19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next、date-fns、dnd-kit。
